## English

- On GNOME Wayland, a denied screenshot request now offers a clear recovery path in the Library. **Request Access** asks the desktop for persistent screenshot permission, and **Retry Capture** resumes capture after approval. Existing screen recording permission is unaffected.
- Keep error notices visible even when a backend error names an unavailable icon.
- Improve the Windows package smoke test so controls below the visible settings area are reached before testing them.

Install the Ubuntu 24.04 x64 package with `sudo apt install ./kiri_1.6.4_amd64.deb`. On macOS and Windows, use the assets for your platform below. The macOS app retains Kiri's stable local signing identity and is not Apple-notarized; if the first launch is blocked, choose **Open Anyway** in System Settings → Privacy & Security. Windows packages are not Authenticode-signed. Linux still updates by installing a newer `.deb`; Windows Portable updates by replacing the extracted ZIP.

Verification: automated release-tool tests and frontend build passed. GNOME Wayland screenshot permission recovery was exercised in an Ubuntu 24.04 virtual machine. Other feature paths require the platform-specific package checks before publication.

## 中文

- GNOME Wayland 截图授权被拒后，素材库现在会给出明确的恢复入口。「请求权限」向桌面申请持久截图权限，授权后可通过「重试截图」继续。已有的录屏权限不受影响。
- 即使后端错误指定了不存在的图标，也会显示错误提示。
- 改进 Windows 安装包冒烟测试：先滚动到设置页可见区域之外的控件，再验证其功能。

Ubuntu 24.04 x64 可执行 `sudo apt install ./kiri_1.6.4_amd64.deb` 安装；macOS 和 Windows 请下载下方对应平台的文件。macOS 应用沿用 Kiri 的稳定本地签名身份，尚未经过 Apple 公证；首次启动若被拦截，请在「系统设置 → 隐私与安全性」中选择「仍要打开」。Windows 安装包尚未使用 Authenticode 签名。Linux 后续仍通过安装新版 `.deb` 更新；Windows 绿色版需下载新版 ZIP 并替换解压文件。

验证情况：发布工具自动测试和前端构建已通过；GNOME Wayland 截图权限恢复已在 Ubuntu 24.04 虚拟机中验证。其他功能路径需在发布前完成各平台安装包检查。
