## English

- Read QR codes locally from a capture or saved screenshot. Select a center arrow on the original capture or editor image to view Link, Text or WeChat content; the library menu uses the same editor without another preview. Pending edits survive recognition, and loading or failures use compact feedback. Ordinary text with an embedded URL stays Text; readable selected codes are saved in searchable QR Favorites. Open Link uses the default browser in one click. Long content wraps and scrolls without hiding the actions. Multiple-code scans combine contrast passes and overlapping local scans to recover more codes in dense images. Standard square WeChat QR codes are supported; circular Mini Program codes are not.
- Copy videos and GIFs as files from the library or viewer, including Cmd/Ctrl+C in preview. Stopped recordings appear with a saving status while encoding, merging and import finish, including overlapping background saves.
- Add a macOS Show in Dock switch that applies immediately and remembers the choice after relaunch. The tray and capture shortcut remain available when the Dock icon is hidden.
- Keep capture tools usable in narrow selections. In the saved-image editor, preserve pending crops while annotating and retain unsaved-edit warnings after Save As. Improve annotation text undo and IME shortcut handling.
- Preserve GIF playback timing and report the encoded duration. On macOS, show recovery guidance when display changes invalidate starting or resuming a recording. On Linux, align the capture overlay before mapping it and hide capture windows before the first recording frame.

Contributors to this release: @yuxino.

Install the Ubuntu 24.04 x64 package with `sudo apt install ./kiri_1.6.7_amd64.deb`. On macOS and Windows, choose the download for your platform below. The macOS app keeps Kiri's stable local signing identity but is not Apple-notarized; if the first launch is blocked, use **Open Anyway** in System Settings → Privacy & Security. Windows packages are not Authenticode-signed. Linux updates by installing a newer `.deb`, and Windows Portable updates by replacing the extracted ZIP.

Verification: Rust and renderer regression tests, frontend build and release-tool checks passed. The locally signed Universal macOS DMG and updater archive passed signature, disk-image, architecture and minimum-OS checks. Windows installer/portable smoke tests and Ubuntu `.deb` installation/X11 checks run in GitHub Actions. Native macOS video copying was checked by pasting into Finder and comparing file hashes. Dock toggling kept Settings open and the hidden preference survived relaunch. Intel hardware, original-screen QR capture interaction, long-recording finalization and all GNOME Wayland/display configurations have not been fully exercised on devices in this round.

## 中文

- 在截图或已有图片中本地识别二维码。在截图或编辑器原图上直接点击中心箭头，查看链接、文字或微信内容；素材库菜单也进入同一编辑器，不再另开预览。识别保留待保存修改，加载和失败只显示简短提示。含有链接的普通文字仍归为文字；读出的所选二维码自动加入可搜索的「二维码收藏」。点击一次「打开链接」即可使用默认浏览器打开。长内容换行并滚动，操作按钮始终可用。多码识别结合不同对比度与重叠局部扫描，改善密集图片的漏识别。支持微信普通方形二维码，暂不支持圆形小程序码。
- 可在素材库或预览中复制视频和 GIF 文件，预览支持 Cmd/Ctrl+C。录屏停止后立即显示「保存中」，覆盖编码、合并和导入过程，也可同时显示多个后台保存任务。
- macOS 设置新增「在 Dock 中显示」开关，立即生效，重启后保留选择；隐藏图标后仍可使用菜单栏和截图快捷键。
- 优化窄选区内的截图工具。已保存图片的编辑器中，标注时保留待保存裁剪，另存后仍保留未保存修改的关闭确认；改善文字撤销和输入法组合输入期间的快捷键处理。
- GIF 导出保留播放节奏，并显示实际编码时长。macOS 在显示器变化导致无法开始或恢复录制时提供恢复指引。Linux 在显示截图浮层前对齐位置，并在录制第一帧前隐藏截图窗口。

本次版本贡献者：@yuxino。

Ubuntu 24.04 x64 可执行 `sudo apt install ./kiri_1.6.7_amd64.deb` 安装；macOS 和 Windows 请下载下方对应平台的文件。macOS 应用沿用 Kiri 的稳定本地签名身份，但尚未经过 Apple 公证；首次启动若被拦截，可在「系统设置 → 隐私与安全性」中选择「仍要打开」。Windows 安装包尚未使用 Authenticode 签名。Linux 通过安装新版 `.deb` 更新；Windows 绿色版需下载新版 ZIP 并替换解压文件。
