## English

- Show each image, video and GIF file size beside its dimensions. Switching media tabs, favorites or filters returns the library to the top. Import, paste and other operation results use compact floating toasts that do not shift the content.
- Move and resize annotations directly, including after reopening an image, without leaving a second copy at the original position. Improve wrapped-text sizing and hit bounds, keyboard font changes, tab alignment, undo and shared styling across editor windows.
- Preserve image transparency and convert supported embedded color profiles to sRGB on import. Keep cropped text backgrounds and mosaics consistent after saving and reopening. Improve dense, mixed-contrast QR recognition; blank OCR results show an empty state, and corrected OCR history refreshes open views.
- On Linux, keep X11 capture aligned to the full display when desktop panels reserve space, without shifting or clipping the overlay. Restore MP4/MOV playback, pausing and seeking. Improve countdown Escape cancellation, recording startup frames, rotated-video GIF conversion and focus return to the source application. Reopened minimized editors and pinned images return to view; fresh pin controls reflect the actual always-on-top state.
- Release Linux WebKitGTK IPC receivers when their windows close, fixing a reference cycle that retained renderers.

Contributors to this release: @yuxino.

Install the Ubuntu 24.04 x64 package with `sudo apt install ./kiri_1.6.8_amd64.deb`. On macOS and Windows, choose the download for your platform below. The macOS app keeps Kiri's stable local signing identity but is not Apple-notarized; if the first launch is blocked, use **Open Anyway** in System Settings → Privacy & Security. Windows packages are not Authenticode-signed. Linux updates by installing a newer `.deb`, and Windows Portable updates by replacing the extracted ZIP.

Verification: 321 local Rust tests and 297 renderer/tool tests, Cargo checking and the frontend build passed. Installed Ubuntu 24.04 packages are checked on isolated X11 and GNOME 46 Wayland software desktops at scales 1, 1.25, 1.5 and 2. The X11 panel repair also passed an official candidate package on the original Debian/XFCE desktop. Original Debian/XFCE/X11 acceptance for [#82](https://github.com/yuxino/kiri/issues/82) combines the earlier 23-case retest, focused repair checks and subsequent native action regressions; it is not a new 23/23 sweep of this release package. OCR confirmation keyboard routing was checked with isolated production UI and blocked network transport, not a real remote provider. Physical GPU, mixed-display DPI, real IME and Intel hardware coverage remain limited. The new library layout and live movement were checked with isolated browser fixtures; native acceptance of these new interactions remains limited.

Full changelog: [v1.6.7 → v1.6.8](https://github.com/yuxino/kiri/compare/v1.6.7...v1.6.8).

## 中文

- 在图片、视频和 GIF 的尺寸旁显示文件大小。切换素材分类、收藏或筛选时回到顶部。导入、粘贴等操作结果改为简洁的浮动提示，不再挤动页面内容。
- 移动和缩放标注时直接更新位置，保存后再次编辑也不会在原处留下第二份标注。改善换行文字的字号与点击范围、键盘调节字号、制表符对齐、撤销及多个编辑窗口之间的样式同步。
- 导入时保留图片透明度，并将支持的内嵌色彩配置转换为 sRGB。裁剪后的文字背景和马赛克在保存、重开后保持一致。改善密集图片中不同对比度二维码的识别；空白 OCR 显示空结果，修改历史文字后刷新已打开的视图。
- Linux 在桌面面板占用工作区时仍按完整显示器定位截图，避免选框下移或底部裁切。恢复 MP4/MOV 播放、暂停和拖动进度，改善倒计时 Esc 取消、录制起始帧、旋转视频转 GIF 和返回来源应用的焦点。再次打开最小化的编辑器或贴图时恢复窗口；首次贴图的置顶按钮正确反映实际状态。
- 修复 Linux WebKitGTK 的 IPC 引用环，关闭窗口后释放接收端，避免继续保留对应渲染进程。
