## English

- Set up desktop-approved Capture, Pause/Resume and Stop shortcuts on Wayland desktops that support the GlobalShortcuts Portal. Settings show confirmed bindings and provide reconnect/disconnect controls. Manual command shortcuts remain available; Ubuntu 24.04 / GNOME 46 still uses that route.
- Record Linux MP4 videos with system sound, microphone, both or neither. Use an explicit microphone check and keep MP4 audio preferences when switching to silent GIF recording. Audio uses the local PulseAudio or PipeWire-Pulse service; devices and permissions are not changed automatically.
- Trim, split, delete and reorder Linux video clips at normal speed, then export a separate MP4 with synchronized source audio and size presets. Original media stays unchanged. Speed changes, effects, masks, annotations and stickers remain unavailable; projects containing them stay intact and read-only. Required GStreamer codecs must be installed.

Contributors to this release: @yuxino.

Install Linux with `sudo apt install ./kiri_1.6.9_amd64.deb` so its declared dependencies are resolved. Linux updates by replacing the `.deb`; Windows Portable updates by replacing its ZIP. macOS and installed Windows builds use the signed, user-initiated updater. macOS retains Kiri's stable local signing identity and is not Apple-notarized; if blocked, use **System Settings → Privacy & Security → Open Anyway**. Windows packages are not Authenticode-signed.

Verification: the [integrated candidate](https://github.com/yuxino/kiri/actions/runs/37111543995) and [merged source](https://github.com/yuxino/kiri/actions/runs/37114126641) passed their selected checks. The exact candidate package passed native Debian/XFCE playback, seeking, pausing, saved-project reopening, audio-preference and export checks. Independent decoding confirmed a 1.3-second reordered AAC export and a 2.1-second silent export; source files remained unchanged. Private-service and simulated tests cover unavailable devices and desktop environments within this release's accepted scope. Physical microphones, hardware playback, GNOME 48+/KDE shortcut consent and mixed-scale physical displays were not tested. In-flight export cancellation is covered by native contract tests, not claimed as a GUI pass. The new version's packages are rebuilt and checked separately; attached provenance records their source and hashes. Automatic release checks do not run the Linux desktop harnesses that configure accessibility or screen-lock settings; those skipped checks are not passes.

Full changelog: [v1.6.8 → v1.6.9](https://github.com/yuxino/kiri/compare/v1.6.8...v1.6.9).

## 中文

- 在支持 GlobalShortcuts Portal 的 Wayland 桌面中，通过桌面授权设置截图、暂停/继续录制和停止录制快捷键。设置页显示已确认的绑定，并提供重连和断开操作。手动命令快捷键继续保留；Ubuntu 24.04 / GNOME 46 仍使用这一方式。
- Linux MP4 录制可选择系统声音、麦克风、两者混合或无声，并提供主动触发的麦克风检查。切换到无声 GIF 录制时保留 MP4 音频偏好。音频使用本机 PulseAudio 或 PipeWire-Pulse 服务，不会自动改变设备和权限。
- Linux 视频支持正常速度的裁切、分割、删除和片段重排，并按尺寸预设导出保留同步原声的新 MP4。源素材保持不变。变速、特效、遮罩、标注和贴纸仍不可用；包含这些内容的工程会完整保留并以只读方式打开。需要安装相应 GStreamer 编码器。

本次版本贡献者：@yuxino。

Linux 请用 `sudo apt install ./kiri_1.6.9_amd64.deb` 安装，以解析声明的依赖。Linux 通过替换 `.deb` 更新；Windows 绿色版通过替换 ZIP 更新。macOS 和 Windows 安装版使用用户主动触发的签名更新。macOS 沿用 Kiri 的稳定本地签名身份，尚未经过 Apple 公证；若被拦截，可在「**系统设置 → 隐私与安全性 → 仍要打开**」中批准。Windows 包尚未使用 Authenticode 签名。

验证情况：[集成候选](https://github.com/yuxino/kiri/actions/runs/37111543995)和[合并主线](https://github.com/yuxino/kiri/actions/runs/37114126641)选定的检查通过。确切候选包通过 Debian/XFCE 原生播放、拖动进度、暂停、工程保存重开、音频偏好和导出检查。独立解码确认了 1.3 秒 AAC 重排导出和 2.1 秒无声导出，源文件保持不变。本轮无法提供的设备和桌面环境在约定范围内由私有服务及模拟测试覆盖；未实际测试物理麦克风、硬件播放、GNOME 48+/KDE 快捷键授权及实机混合缩放。导出中的取消由原生契约测试覆盖，不称为界面验收通过。新版安装包另行重建和检查，所附 provenance 记录各包来源和校验值。自动发布检查不运行会配置无障碍或锁屏设置的 Linux 桌面测试；这些跳过项不算通过。

完整变更：[v1.6.8 → v1.6.9](https://github.com/yuxino/kiri/compare/v1.6.8...v1.6.9)。
