## English

- Add Linux packages for Ubuntu 24.04 x64 with GNOME and X11: screenshots, editable annotations, local OCR, and silent MP4/GIF recording. Wayland capture uses the desktop permission dialogs and supports one connected display.
- Add a Windows x64 Portable package. Download the `Portable.zip`, extract it, and run `kiri.exe` directly without using the installer.
- Keep the existing Windows NSIS installer and signed in-app updater artifacts unchanged.

Install Linux with `sudo apt install ./kiri_1.6.3_amd64.deb`. Use the same command with each newer package to update. English, Simplified Chinese, and Japanese OCR data and media dependencies are installed automatically. On Wayland, assign `kiri --capture` to a desktop shortcut; recordings are paused and stopped from the tray or desktop commands. Linux audio, click highlights, video editing, and in-app installation are unavailable. See the [Linux guide](https://github.com/yuxino/kiri/blob/v1.6.3/docs/linux.md) for setup and controls.

The Portable package is intended for users who prefer an extract-and-run build. Like the Windows installer, it is not Authenticode-signed.
The library and settings remain in the Windows user profile. Portable users update by downloading a new ZIP from Releases; the in-app NSIS installer update is not offered.

macOS packages retain Kiri's stable local signing identity. They are not Apple-notarized; if the first launch is blocked, use **Open Anyway** in System Settings → Privacy & Security.

Thanks to [@kerwin2046](https://github.com/kerwin2046) for the initial Linux implementation in [PR #20](https://github.com/yuxino/kiri/pull/20), and for the time and care put into it.

## 中文

- 新增 Ubuntu 24.04 x64 的 Linux 安装包，支持 GNOME 和 X11，可截图、编辑标注、离线识别文字和录制无声 MP4/GIF。Wayland 捕获通过系统对话框授权，支持连接一台显示器。
- 新增 Windows x64 绿色版（Portable）。下载 `Portable.zip` 后解压，直接运行 `kiri.exe`，无需安装。
- 保留现有 Windows NSIS 安装包和应用内更新签名产物，不改变原有安装与更新流程。

Linux 执行 `sudo apt install ./kiri_1.6.3_amd64.deb` 安装；后续下载新版软件包后使用相同命令更新。英文、简体中文和日文 OCR 数据与媒体依赖会自动安装。Wayland 请将 `kiri --capture` 绑定到桌面快捷键；录屏通过托盘或桌面命令暂停、停止。Linux 暂不提供声音、点击高亮、视频剪辑和应用内安装更新。配置与操作方式见 [Linux 指南](https://github.com/yuxino/kiri/blob/v1.6.3/docs/linux.md)。

绿色版适合希望解压即用的用户。与 Windows 安装包一样，目前未做 Authenticode 签名。
素材库与设置仍保存在 Windows 用户目录中。绿色版请从 Releases 下载新版 ZIP 手动更新，不提供应用内 NSIS 安装更新。

macOS 安装包沿用 Kiri 的稳定本地签名身份，未经过 Apple 公证。首次启动若被拦截，请在「系统设置 → 隐私与安全性」中选择「仍要打开」。

感谢 [@kerwin2046](https://github.com/kerwin2046) 在 [PR #20](https://github.com/yuxino/kiri/pull/20) 中提供 Linux 初始实现，以及为此投入的时间与心力。
