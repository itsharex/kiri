## English

- Adjust a selected line or arrow by dragging its endpoints or stroke without switching away from the drawing tool.
- Optional recorded click highlights now use a red ring that is easier to see on light backgrounds.
- Correct saved OCR text in Text History and restore the original recognition result when needed. Search and Copy Text use the correction.
- Paste a clipboard image into the local library with **Paste Image** or Cmd+V / Ctrl+V, then annotate it or run local OCR. Kiri reads the clipboard only when you invoke this action.
- Export selected library files to a folder in one step. Existing files are not overwritten, and the library originals remain in place.
- Pin a saved screenshot in a movable reference window. **Unpin** removes its always-on-top setting; closing the window leaves the saved image untouched. Wayland compositors may not honor always-on-top requests.

Install the Ubuntu 24.04 x64 package with `sudo apt install ./kiri_1.6.5_amd64.deb`. On macOS and Windows, choose the download for your platform below. The macOS app keeps Kiri's stable local signing identity but is not Apple-notarized; if the first launch is blocked, use **Open Anyway** in System Settings → Privacy & Security. Windows packages are not Authenticode-signed. Linux updates by installing a newer `.deb`, and Windows Portable updates by replacing the extracted ZIP.

Verification: release-tool tests, frontend build, and Rust tests passed. CI built and tested the Windows installer and Portable ZIP, Linux `.deb` and isolated X11/Wayland paths, and macOS arm64/x64 targets. The locally signed Universal macOS DMG and updater archive passed signature, disk-image, architecture, and minimum-OS checks. The new interactions have not been manually exercised on every supported desktop and display server.

## 中文

- 选中直线或箭头后，无需切换绘制工具，就能拖动端点或线身进行调整。
- 开启点击高亮后，录制视频中的点击位置改用红色圆环，在浅色背景上更容易看清。
- 素材库的「文字记录」现在可以修正 OCR 结果，也能恢复最初识别的文字。搜索和复制会使用修正后的内容。
- 可通过「粘贴图片」或 Cmd+V / Ctrl+V，将剪贴板图片导入本地素材库，再进行标注或本地 OCR。只有主动触发时，Kiri 才会读取剪贴板。
- 一次将选中的素材导出到指定文件夹；遇到同名文件不会覆盖，素材库中的原件也不会移动。
- 可将已保存的截图固定为可移动的参考窗口。「取消置顶」会让窗口不再保持最前，关闭窗口也不会删除截图。Wayland 桌面可能不支持置顶请求。

Ubuntu 24.04 x64 可执行 `sudo apt install ./kiri_1.6.5_amd64.deb` 安装；macOS 和 Windows 请下载下方对应平台的文件。macOS 应用沿用 Kiri 的稳定本地签名身份，但尚未经过 Apple 公证；首次启动若被拦截，可在「系统设置 → 隐私与安全性」中选择「仍要打开」。Windows 安装包尚未使用 Authenticode 签名。Linux 通过安装新版 `.deb` 更新；Windows 绿色版需下载新版 ZIP 并替换解压文件。

验证情况：发布工具测试、前端构建及 Rust 测试通过。CI 已构建并测试 Windows 安装包和绿色版 ZIP、Linux `.deb` 及隔离的 X11/Wayland 路径，并完成 macOS arm64/x64 编译。本地签名的 macOS Universal DMG 和更新压缩包通过签名、磁盘映像、架构及最低系统版本检查。新增交互尚未在每种受支持的桌面和显示服务器上逐一手动验证。
