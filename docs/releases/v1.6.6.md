## English

- Make the optional red click highlight in recordings smaller and lighter. It now uses one thin ring and a small center point.
- Keep the Windows capture overlay aligned when the system text size differs from 100%, and report a clearer error if display scale pinning fails.

Contributors to this release: @LLLin000 (Windows text scaling), @yuxino (click highlight and release).

Thanks also to [@kerwin2046](https://github.com/kerwin2046) for Kiri's earlier Linux implementation in [PR #20](https://github.com/yuxino/kiri/pull/20).

Install the Ubuntu 24.04 x64 package with `sudo apt install ./kiri_1.6.6_amd64.deb`. On macOS and Windows, choose the download for your platform below. The macOS app keeps Kiri's stable local signing identity but is not Apple-notarized; if the first launch is blocked, use **Open Anyway** in System Settings → Privacy & Security. Windows packages are not Authenticode-signed. Linux updates by installing a newer `.deb`, and Windows Portable updates by replacing the extracted ZIP.

Verification: 158 release-tool tests, the frontend build, and 267 Rust tests passed. The locally signed Universal macOS DMG and updater archive passed signature, disk-image, architecture, and minimum-OS checks. Windows and Linux package checks run in GitHub Actions. The new click highlight has not yet been visually checked in a finished recording on every supported desktop.

## 中文

- 调轻录制时可选的红色点击高亮：改为一道较细的圆环和一个小圆点，减少对画面的遮挡。
- 修正 Windows 系统文字大小不是 100% 时截图选区的对齐问题；显示器缩放设置失败时会给出更明确的错误。

本次版本贡献者：@LLLin000（Windows 文字缩放修正）、@yuxino（点击高亮与发布）。

也感谢 [@kerwin2046](https://github.com/kerwin2046) 此前在 [PR #20](https://github.com/yuxino/kiri/pull/20) 中为 Kiri 提供 Linux 初始实现。

Ubuntu 24.04 x64 可执行 `sudo apt install ./kiri_1.6.6_amd64.deb` 安装；macOS 和 Windows 请下载下方对应平台的文件。macOS 应用沿用 Kiri 的稳定本地签名身份，但尚未经过 Apple 公证；首次启动若被拦截，可在「系统设置 → 隐私与安全性」中选择「仍要打开」。Windows 安装包尚未使用 Authenticode 签名。Linux 通过安装新版 `.deb` 更新；Windows 绿色版需下载新版 ZIP 并替换解压文件。

验证情况：158 项发布工具测试、前端构建及 267 项 Rust 测试通过。本地签名的 macOS Universal DMG 和更新压缩包通过签名、磁盘映像、架构及最低系统版本检查。Windows 和 Linux 安装包检查由 GitHub Actions 运行。新版点击高亮尚未在所有受支持桌面的成片中逐一进行目视检查。
